# DankNDevour Linktree

A simple, clean linktree page for DankNDevour with social media links and "Join the Dank Network" CTA.

## Features

- Clean, minimal linktree design
- Social media links (Instagram, YouTube, Twitter, Email)
- Google Analytics integration
- Responsive design
- Dark theme

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Google Analytics
